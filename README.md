# Daily Math 🧠

A simple Chrome extension that gives you one short math challenge every day.

The goal is to build a small daily habit of mental-math practice and problem solving.

## Features

- 🧮 One math challenge every day
- ✅ Instant answer checking
- 💡 Short mental-math explanation
- 🔥 Daily streak tracking
- 💾 Progress stored locally in Chrome
- 🔒 No account required
- 🌐 No external server or API
- 🚫 No browsing activity tracking

## How It Works

Each day, Daily Math generates one math problem for you to solve.

For example:

> **47 × 19 = ?**

Enter your answer and check it.

If you're correct, the extension shows a short explanation and updates your daily streak.

The same question remains available throughout the day. A new question is generated on the next day.

## Privacy

Daily Math does not collect or transmit personal information or browsing activity.

The extension stores only the information required for the daily challenge and streak locally in Chrome using the Chrome Storage API.

See the [Privacy Policy](privacy-policy.html).
